# JetBrainsMono NF webfonts

JetBrains Mono 2.304, patched by Nerd Fonts 3.3.0.
Converted from the locally installed JetBrainsMonoNerdFont TTF files to WOFF
with fontTools; all glyphs are preserved.

Upstream: https://github.com/ryanoasis/nerd-fonts

Distributed under the SIL Open Font License 1.1; see OFL.txt.
Served with the docs without a local font installation or external CDN.
