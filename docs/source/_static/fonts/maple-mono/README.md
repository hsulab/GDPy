# Maple Mono webfonts

Unmodified WOFF2 fonts from Maple Mono v7.9:
https://github.com/subframe7536/maple-font/releases/download/v7.9/MapleMono-Woff2.zip

Copyright 2022 The Maple Mono Project Authors.
Distributed under the SIL Open Font License 1.1; see LICENSE.txt.

These are the standard Maple Mono webfonts, without the desktop NF/CN extensions.
The fonts are served with the documentation and need no local installation or CDN.
Only the filenames have been shortened from `.ttf.woff2` to `.woff2`.
