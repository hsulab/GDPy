(ga-adsorbate-insertion-example)=

# Site-based adsorbate insertion

This example searches CO adsorption structures on a supported Cu4 cluster using
the `adsorbate_insertion` builder. It complements the
{ref}`ga-supported-cluster-adsorbate-example`, where the random-structure
builder generates Cu4 and CO together inside one spatial region.

## Supported cluster and adsorption sites

The builder starts from
`examples/global_optimisation/assets/cu4_alumina111_supported.xyz`, containing
a tagged Cu4 cluster on the thin orthogonal α-Al₂O₃(0001) slab. The 180 support
atoms have tag 0, and the four Cu atoms have distinct positive tags. The
structure is one reproducible candidate generated by the
{ref}`ga-supported-nanoparticle-example`.

The site definition selects the Cu atoms with the group expression
`` `symbol Cu` ``. A 3.0 Å graph cutoff identifies the Cu cluster connectivity,
and `max_order: 1` enables atop and bridge sites. The supplied Cu4 structure
provides four atop and six bridge sites. For each initial candidate, the
builder randomly selects one valid site and places CO along its outward site
normal with C as the contact atom.

:::{note}
`adsorbate_insertion` requires a substrate that already contains the supported
cluster. It inserts only CO in this example; it does not generate the four Cu
atoms. The subsequent crossover, mutation, and relaxation can still change the
Cu4 structure because its atoms have positive tags.
:::

## Input

The complete configuration is available at
`examples/global_optimisation/explorations/genetic_algorithm/cu4_co_alumina111_adsorbate_insertion.yaml`:

```{literalinclude} ../../../../examples/global_optimisation/explorations/genetic_algorithm/cu4_co_alumina111_adsorbate_insertion.yaml
:language: yaml
```

Pair this exploration with the following runtime (passed with `--runtime`):

```{literalinclude} ../../../../examples/global_optimisation/runtimes/mattersim_alumina_min_100.yaml
:language: yaml
```

The only named builder is `adsorbate`, so `reference_builder: adsorbate`
identifies it as the source of substrate and bond-distance metadata. The CO
atoms share one positive tag, so default fragment preservation makes periodic
cut-and-splice crossover and rattle mutation treat CO as one particle. The
bottom Al–O–Al slab unit is fixed with `constraint: lowest 60`.

MatterSim is used because the potential must describe Cu, C, O, Al, and their
interfaces. See the {ref}`potential-mattersim` guide for installation and model
details.

## Run

After installing MatterSim, run from the repository root:

```shell
gdp -d ./run-cu4-co-adsorbate-insertion \
    --runtime ./examples/global_optimisation/runtimes/mattersim_alumina_min_100.yaml explore \
    ./examples/global_optimisation/explorations/genetic_algorithm/cu4_co_alumina111_adsorbate_insertion.yaml
```

The search is stored under
`run-cu4-co-adsorbate-insertion/expedition-0`. The initial population samples
the graph-derived adsorption sites, while later generations apply crossover
and mutation to the complete tagged Cu4–CO system.

:::{note}
The supplied supported cluster, thin slab, small population, and single
generation are intended for demonstrating the builder. Sample several
supported-cluster structures and converge all search settings for a scientific
adsorption study.
:::
