# Benchmarks

Timing scripts, plotting tools, and recorded measurements belong here.
For runnable demonstrations, see the [computation guide](../docs/source/computations/index.md)
and inputs under `examples/`.
Run benchmark commands from the repository root in your GDPy environment.

- [Water-box MD](water_md/README.md): xreac and MatterSim, with a hard three-minute total limit.
- [Water-cluster relaxation](water4_relaxation/README.md): warmed force calls and equal-step relaxations, plus historical GA timings.

Each study documents its systems, dependencies, conditions, and limitations.
Recorded results describe the measured versions and hardware; rerunning with
newer packages can produce different timings. Historical result files are
preserved unchanged.
